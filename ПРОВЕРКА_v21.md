# Проверка версии 21 — что нашли и что исправили

Дата: 12.11.2026. Проверяли весь сайт: страницы, кнопки, клавиши, мобильная ширина,
английская версия, API, БД, тесты и голос на сервере.

## Найдено и исправлено

| № | Что было не так | Как исправили |
|---|---|---|
| 1 | **Редактор испытания не работал**: страница не знала номер испытания (`/api/tests/NaN`), поэтому вопрос не добавлялся и публикация не срабатывала — преподаватель физически не мог собрать тест через интерфейс | номер берётся из блока `edit-config`, запасные пути — `data-test-id` и адрес страницы; если номера нет, показывается понятная ошибка, а не «тихий» отказ |
| 2 | **Можно было сохранить вопрос, на который нельзя ответить** (варианты пустые, верный ответ не из списка) | проверка на сервере и в браузере: минимум два варианта, верный обязан быть среди них, у одиночного — ровно один |
| 3 | **В обучении можно было ответить второй раз** после вердикта — то есть выбрать правильный вариант, увидев ответ | сервер отвечает 409 «на этот вопрос уже есть ответ», варианты в браузере блокируются сразу после ответа |
| 4 | **Клавиши 1–4 не работали** сразу после выбора раздела (фокус оставался на кнопке каталога) | перехват клавиш во всём документе; в поле ввода цифры остаются текстом ответа; Enter на кнопке не срабатывает дважды |
| 5 | **Ошибки в API `POST /voice`** — падало с 500 на пустой расшифровке | 422 «Пустая фраза», без падения |
| 6 | **Неизвестный раздел** видеотеста молча открывал «Все разделы» | 422 «Нет такого раздела» |
| 7 | **Пустой ответ** (`text: "   "`) засчитывался как ошибка | 422 «Пустой ответ», в зачёт не идёт |
| 8 | **Формы теряли введённое** при ошибке входа и регистрации (почта, ФИО, группа) | поля заполняются обратно; пароль, как и положено, не возвращается |
| 9 | **Пароль: при регистрации 6 символов, при смене 8** — путаница | везде 8, подписи в формах и подсказки обновлены |
| 10 | **Битые таблицы**: в пяти шаблонах цикл выводил ячейки без строки `<tr>` (браузер чинил сам, вёрстка и адаптив могли поехать) | `<tr>` на месте, проверено на всех таблицах |
| 11 | **Старые скрипты из кэша** на шести страницах (ссылки без `?v=`) — после обновления браузер мог показать прежний файл | у всех скриптов и стилей одна версия `?v=21`; добавлен тест, который это стережёт |
| 12 | **Лимит времени задания** показывался на карточке, но в прохождении о нём не было ни слова | в шапке прохождения «лимит N мин», таймер краснеет после лимита (испытание молча не обрывается — ответы не теряются) |
| 13 | **Загрузка модели голоса** писала неверный размер (221 МБ вместо 75) | размер считается по настоящим файлам модели |
| 14 | **Преподаватель мог сам «пройти» испытание** — его попытки попадали в статистику | прохождение только для учащихся: API 403, страницы перенаправляют |
| 15 | **Единичные числа в англ. версии**: «1 questions» | «1 question», «1 point» |
| 16 | **`/transcribe` отвечал 500** на битую или слишком длинную запись | 422 (битая) и 413 (длиннее 4 МБ) |

## Что проверили и что осталось как есть

- **Все страницы** (19 маршрутов, две роли): 200, ошибок JS — 0, запросов с ошибкой — 0, мусора вида `undefined`/`{{ }}` — 0.
- **Видеотест**: каталог и бейджи, подсветка режима, заход ровно 20 из 20, вердикт с текстом правильного ответа,
  блокировка вариантов, разбор в конце, история без дублей, «пройти ещё раз», клавиши 1–4, английская версия.
- **Голос**: запись уходит на `/transcribe` (~43 КБ на фразу), ответ «не засчитан — повторите» при непонятной фразе;
  серверное включение `VOICE_ENABLED=1` проверено с моделью `tiny` (75 МБ).
- **Обычное испытание**: старт, ответы (вариант, несколько, текст), камера/микрофон, завершение, разбор, ручная
  оценка преподавателем (2,5 балла сохраняются), прерывание.
- **Мобильная ширина 390 px**: ни на одной странице нет горизонтальной прокрутки.
- **Английская версия**: переводится вся оболочка; по-русски остаются только данные, которые создал преподаватель
  (названия испытаний, вопросы, варианты) — это содержимое БД, а не интерфейс.
- **Сознательно не меняли**: время испытания не прерывается автоматически (иначе потерялись бы ответы);
  заголовки демо-испытаний остаются на русском.
