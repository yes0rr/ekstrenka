# Удалить перед финальной версией

Список временного функционала прототипа. Проверять при сборке финальной версии.

---

## 1. Запись видео на сервер (обучение модели)

**Решение от 26.10.2026:** включаем запись на сервер ТОЛЬКО на время, пока обучаем модель.
В конечной версии видеозаписи на сервере быть не должно — только числа анализа
и (по желанию) запись на устройство студента.

### Как должно быть устроено, пока включено

| Параметр | Значение |
|---|---|
| Флаг | `RECORD_UPLOAD=1` (по умолчанию `0`) |
| Кто включает | только мы на сервере, не пользователь |
| Куда пишем | `media/recordings/{attempt_id}_{date}.webm`, вне БД и вне git |
| Формат | WebM 480p, 800 кбит/с, ~24 МБ за 4 минуты, куски по 2–5 МБ |
| Срок хранения | 30 дней или до выгрузки датасета, потом автоудаление |
| Согласие студента | обязательный чекбокс «разрешаю использовать запись для обучения модели»; без него файл удаляется после обработки |
| Доступ | только администратор сервера (Женя) и автор испытания |

### Чек-лист удаления перед финалом

- [ ] Убрать приём кусков видео в API (`/recording/*`) — эндпоинты отвечают 404
- [ ] Убрать из UI чекбокс согласия на запись и индикатор «REC» для серверной записи
- [ ] Удалить флаг `RECORD_UPLOAD` из `config.py`, `.env.example`, `env.production.example`
- [ ] Удалить все файлы из `media/recordings/` и саму папку из `.gitignore`/Dockerfile
- [ ] Убрать колонку `recording_status` (или оставить, если нужен исторический факт)
- [ ] Обновить `README_PROJECT.md`, `README_PROGRAM.md`, ТЗ (раздел «данные» и «границы»)
- [ ] Проверить политику обработки ПДн: убрать упоминание видеозаписей
- [ ] Прогнать тесты и убедиться, что без `RECORD_UPLOAD` приложение работает
- [ ] Сделать `grep -rn "RECORD_UPLOAD\|recordings\|recording"` — не должно остаться следов

### Почему убираем

- видео человека — персональные данные, на прототипе допустимо только с согласием и узким кругом;
- в конечной версии ценность даёт анализ (темп, глубина, углы) и повтор по скелету, а не запись;
- доказательством для аттестации видео быть не может (файл легко изменить), нужен датчик в манекене.
