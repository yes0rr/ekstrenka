# Обучение модели «Экстренка» — план v2 (эталон теперь прибор)

**Что изменилось 03.11.2026.** Появилось оборудование-эталон: занятия по БЛС идут на
«Анне» (Laerdal Resusci Anne QCPR) или на тренажёре типа «Максим». У них есть датчики:
глубина компрессий, частота, положение рук, глубина вдоха — и они сами считают
эффективность реанимации, а показания выводятся на планшет.

Это меняет главное: **эталоном становится прибор, а не эксперт с галочками.** Эксперт
остаётся только для выборочной проверки. Из плана уходит самая дорогая и самая спорная
часть — 10–15 часов разметки на 300 попыток и вопрос «а точно ли эксперт прав».

---

## 1. Что обучаем

| Слой | Что это | Обучается |
|---|---|---|
| MediaPipe Pose Landmarker (lite) | 33 точки скелета | нет, готовая модель Google |
| `geometry.py` | углы, темп, глубина из точек | нет, формулы |
| **калибровка** | перевод «камера → сантиметры» по показаниям прибора | **подбирается, новый шаг** |
| `scoring.py` — пороги | сравнение с 100–120/мин и 5–6 см | подбирается |
| наша модель-классификатор | оценка по 18 признакам попытки | **да** |

Порядок: калибровка по прибору → пороги → модель. Модель на некалиброванных данных
учится ошибкам камеры, а не ошибкам техники.

---

## 2. Что даёт тренажёр с датчиками

| Показатель прибора | Что с ним делаем | Есть ли у нас сейчас |
|---|---|---|
| Глубина компрессий, мм | **эталон для калибровки и метка «глубина в норме»** | нет, только оценка камеры |
| Частота компрессий, /мин | эталон для темпа и ритма | нет |
| Полнота расслабления, % | новая метка (в паспорте «пальцы оттягивают вверх») | нет |
| Положение рук (центр / не центр) | новая метка + обучение камеры видеть это | нет |
| Глубина вдоха, мл | метка для вентиляции; камере нужен вид на мешок | нет |
| Доля компрессий, % | проверка «не прерывая КГК» | нет |
| Итоговый протокол попытки | файл/печать/экспорт с планшета | нет |

Что это даёт по существу: вместо «модель против мнения эксперта» получаем
**«модель против прибора»** — воспроизводимо, без человеческой усталости, и по величинам,
а не по галочкам.

---

## 3. Главный сдвиг: калибровка глубины по прибору

Самый большой риск плана был в глубине: MediaPipe считает её по «мировым» координатам,
и при наклоне камеры они врут (на реальном ролике станции ЭМП камера стояла под 45° —
и наш код честно отказался считать глубину).

Теперь риск снимается не «более умной моделью», а калибровкой:

1. На занятии камера и тренажёр работают одновременно.
2. По каждой попытке берём два числа: размах запястий **по камере** (в метрах MediaPipe)
   и глубину **по прибору** (в мм).
3. Строим простую зависимость (линейную, по 30–50 попыткам) и получаем перевод
   «камера → настоящие сантиметры» **для конкретной расстановки камеры**.
4. Дальше глубина считается камерой с поправкой — и проверяется на новых попытках.

Коэффициент пересчёта привязан к ракурсу, поэтому калибровку делаем один раз
на каждую точку съёмки и повторяем при смене камеры или её положения.

## 4. Этапы

| № | Этап | Что делаем | Данных | Время | Что считается успехом |
|---|---|---|---|---|---|
| 0 | Разведка оборудования | смотрим «Анну»/«Максим»: что показывает планшет, есть ли выгрузка протокола, как ставить камеру рядом | 2–3 попытки | 2 часа | понятно, как забирать числа прибора |
| 1 | Синхронизация | камера + прибор одновременно; хлопок в начале попытки как метка времени | 5–10 попыток | 1 вечер | время попытки совпадает ±0,2 с |
| 2 | **Калибровка глубины** | 30–50 попыток разной глубины (мелко / в норму / глубоко) | 30–50 | 1–2 занятия | ошибка глубины ≤ 0,5 см против прибора |
| 3 | Калибровка темпа | те же попытки, но с метрономом: 90 / 110 / 130 в минуту | 20–30 | 1 занятие | темп ±5 уд/мин |
| 4 | Первый датасет | обычные занятия по БЛС, метки — из протокола прибора | 100–150 | 2–3 занятия | таблица `dataset.csv` без пропусков |
| 5 | Модель v1 | регрессия / бустинг на 18 признаках, проверка по студентам | 100–150 | вечер на ноутбуке | каппа ≥ 0,7 по каждому критерию |
| 6 | Добор данных | до 300–400 попыток, добавить полноту расслабления и положение рук | 300–400 | 4–6 недель | модель стабильна между занятиями |
| 7 | Модель v2 (последовательности) | 1D-CNN по 30 кадрам, если табличная не дотянула | 300–1000 | 1–2 дня на GPU | прирост подтверждён на новых людях |
| 8 | Внедрение | модель отвечает, при неуверенности — откат на пороги | — | 2–3 дня | в жизни не хуже 5–10 % от проверки |

Экспертная разметка остаётся только для 10 % попыток — чтобы знать, что прибор и эксперт
не расходятся принципиально.

---

## 5. Как теперь мерить качество

Появились непрерывные величины, поэтому одной каппой не обойтись.

| Тип метрики | Чем мерить | Порог «внедряем» |
|---|---|---|
| Глубина | средняя абсолютная ошибка (MAE), см + график расхождения (Bland–Altman) | ≤ 0,5 см |
| Частота | MAE в уд/мин | ≤ 5 |
| Ритмичность | коэффициент вариации против прибора | ≤ 0,05 |
| «В норме / не в норме» (5 критериев) | каппа Коэна против прибора | ≥ 0,7 |
| Согласие прибор ↔ эксперт | каппа на 10 % попыток | ≥ 0,6 |

Правило прежнее: не дотянули — модель не внедряем, работают пороги `scoring.py`.
Это нормальный результат, а не провал.

## 6. Как снимаем

Одно занятие = 10–15 попыток, 1,5–2 часа. Порядок:

1. Камера сбоку, 2–3 м, уровень груди, в кадре голова, плечи и кисти целиком
   (схема — на странице прохождения).
2. Планшет в кадр НЕ берём: в кадре только испытуемый. Номер попытки связываем листком
   с кодом рядом с планшетом на фото, а время — хлопком в начале записи.
3. Хлопок в начале попытки — метка синхронизации.
4. Имя файла `s01_01.webm`, протокол прибора — `s01_01_protocol.txt` (или скриншот).
5. Согласие на запись — до первой попытки.
6. Видео храним 30 дней, дальше удаляем: в датасете остаются только числа.

Датасет расширяется: к прежним колонкам добавляются `ref_depth_cm`, `ref_tempo_bpm`,
`ref_recoil_pct`, `ref_hand_pos`, `ref_vent_ml`, `device` (anna / maksim).

## 7. Что это меняет для станции ЭМП

Ничего не ломает, а разводит два контура:

- **БЛС (учебные занятия)** — полная техника по камере, эталон — прибор. Здесь обучаем модель.
- **ЭМП (аккредитация)** — глубину не меряем вообще. Камера проверяет то, что видно и не
  касается силы нажатия: «не прикасался к пациенту» при оценке ритма и разряде, начало КГК
  в 20 секунд, проверка дыхания ≥ 10 секунд, перчатки, электроды без остановки КГК.
  Знания (препараты, дозы, ЭКГ) закрывает платформа вопросами и чек-листом.

Модель, обученная на «Анне», переносится на ЭМП частично: темп и поза — да,
глубина — только при калибровке на конкретной расстановке камеры.

## 8. Что нужно от вуза

| Нужно | Зачем |
|---|---|
| Доступ к «Анне»/«Максиму» на 2–3 занятия | записи и калибровка |
| Выгрузка протокола с планшета (файл или печать) | числа прибора как эталон |
| Камера/штатив или телефон | съёмка сбоку |
| 10–15 испытуемых на занятие | объём данных |
| Согласие на запись | обязательно |

Если доступа к тренажёру не будет — план не рушится: эталоном снова становится эксперт,
только медленнее и с прежними рисками (см. v1 плана).

## 9. Цепочка скриптов (обновится под новые колонки)

```bash
pip install -r requirements-train.txt
python tools/download_pose_model.py

cp train_data/labels.example.csv train_data/labels.csv   # + колонки ref_*
# записи в train_data/videos/, протоколы приборов рядом

python tools/export_dataset.py      # видео → числа камеры (+ ref_* из разметки)
python tools/calibrate_depth.py     # камера → сантиметры, по прибору
python tools/train_model.py --save  # обучение, метрики, отчёт
```

`calibrate_depth.py` — новый скрипт (появится в следующей версии): читает `dataset.csv`,
строит зависимость «размах камеры → глубина прибора», пишет коэффициент в
`train_data/calibration.json` и показывает ошибку в сантиметрах.

## 10. Что остаётся риском

| Риск | Как снимаем |
|---|---|
| Камера стоит не сбоку | предупреждение в интерфейсе (флаг `side_ratio` уже считается) |
| В кадре два человека (аккредитуемый + помощник) | выбор человека по положению кистей у манекена |
| «Максим» и «Анна» дают разные числа | колонка `device`, отдельная проверка согласия между приборами |
| Нет выгрузки протокола | скриншоты планшета + перенос в CSV вручную (10 попыток = 5 минут) |
| Тренажёр изношен, глубину занижает | раз в месяц контрольная попытка с бруском 5 см |
