## Что внутри v21 (актуальная)

Пять замечаний по скриншотам сайта — пять правок.

**1. Вердикт называет ответ словами.** Раньше при неверном ответе в конце теста выводилось «правильный ответ Д»,
хотя букв в зачёте и вовсе нет — порядок вариантов перемешивается. Теперь сервер вместе с номером отдаёт
`correct_text`, и вердикт звучит так: «Неверно — правильный ответ: При вызове скорой помощи, вместе с
остальными данными». Дополнительно: выбранный неверный вариант подсвечивается красным, верный — зелёным.

**2. Серверное распознавание речи.** Голос «не слушал» из-за браузера: в Chrome без сервисов Google Web Speech
сразу отдаёт ошибку «network», в Firefox его нет. Теперь есть второй путь — локальная модель Whisper на нашем
сервере (`faster-whisper`, CPU, бесплатно, по флагу `VOICE_ENABLED=1`):

| Файл | Что делает |
|---|---|
| `backend/app/speech.py` | ленивая загрузка модели, `status()`, `decode_base64()`, декодирование звука в PCM 16 кГц, лимит 4 МБ |
| `backend/app/routers/videoquiz.py` | `GET /api/video-quiz/voice/status`, `POST /api/video-quiz/transcribe` |
| `frontend/js/video_voice.js` | запись с микрофона (MediaRecorder) → base64 → сервер; браузерный Web Speech остался запасным путём |
| `requirements-voice.txt`, `tools/download_voice_model.py` | установка пакета и загрузка модели (base 145 МБ / tiny 75 МБ) |

Аудио не сохраняется: живёт в памяти запроса и выбрасывается; в лог попадает только текст. Ошибки различаются:
503 — модель не включена, 413 — запись длиннее 4 МБ, 422 — пустая или битая запись (раньше было 500).

**3. Режим видно сразу.** Выбранный режим подсвечен галочкой и рамкой, под переключателем — подпись «Режим
„Зачёт“: вариантов не будет — отвечайте текстом или голосом», страница прокручивается к каталогу разделов.
Название режима повторяется бейджем в самом заходе.

**4. Заход всегда 20 вопросов.** `RUN_SIZE = TOTAL`, `pick_questions` добирает недостающие вопросы из общего
банка. «Вызов СМП» (2 своих вопроса) даёт заход из 20: 2 по теме + 18 общих, на карточке — «20 вопросов · по теме: 2»,
в заходе — «1 из 20 … 20 из 20».

**5. Нераспознанный ответ — не ошибка.** В зачёте, если сказанное/введённое не сопоставилось ни с одним
вариантом, сервер возвращает `{accepted: false, retry: true, text, matched}` — ответ можно повторить, в зачёт
он не идёт.

**Дополнение 13.11 (по замечаниям после просмотра сайта):** выбранный раздел подсвечивается и остаётся с
подписью «Открыть снова»; после выбора раздела страница сама прокручивается к плашке захода и первому вопросу;
на карточках вместо одинакового «20 вопросов» — «6 из 20», «4 из 20» и строка «в заходе 20 вопросов»; из
заголовка захода убран дубль названия режима; голосовая подсказка без технических подробностей
(«Голосовой ответ сейчас недоступен — введите ответ текстом»).

**Сплошная проверка всего сайта после сборки** (подробности — `ПРОВЕРКА_v21.md` в архиве) нашла и исправила
16 дефектов, из них два серьёзных: редактор испытания не знал свой номер (`/api/tests/NaN` — вопросы не
добавлялись, публикация не работала) и второй ответ на вопрос в обучении принимался после показа вердикта.
Также: проверка «вопрос без вариантов», клавиши 1–4 сразу после выбора раздела, формы не теряют введённое при
ошибке, пароль везде 8 символов (было 6 при регистрации и 8 при смене), потерянные `<tr>` в пяти таблицах,
старые скрипты из кэша на шести страницах, лимит времени в шапке прохождения, 422/413 вместо 500 на битой
записи, преподаватель больше не может начать попытку.

Проверено: `pytest` — 59 passed; браузер (Chromium) — 19 маршрутов, 0 ошибок JS, каталог и подсветка режима,
заход 20/20, вердикт с текстом ответа, клавиши, английский интерфейс (451 фраза), полный заход на 20 ответов,
редактор испытания с добавлением вопроса и публикацией, прохождение учащимся, ручная оценка, мобильная ширина
390 px без горизонтальной прокрутки, голос: запись уходит на `/transcribe` (~43 КБ на фразу), серверное
распознавание с моделью `tiny` (75 МБ).

## Что внутри v20

Шесть замечаний по видеотесту — шесть правок.

**1. Одна запись на попытку.** Появилась таблица `video_quiz_runs`: заход создаётся при старте
(какие вопросы достались, порядок вариантов), итог считается по сохранённым ответам при завершении.
Повторное нажатие «завершить» отдаёт тот же результат и в историю не пишет. Проверено тестом
`test_finish_writes_exactly_one_result`.

**2. Больше вопросов и разнообразие.** Банк: 9 → **20** вопросов, у каждого — двуязычные тексты и
слова-подсказки для голоса. В заходе — 10 случайных; порядок вопросов и порядок вариантов перемешиваются
при каждом старте.

**3. Зачёт без вариантов.** Экран зачёта показывает только видео и вопрос: ответ вводится текстом или
проговаривается, сервер сопоставляет его со смыслом. Варианты — только в режиме «Обучение».

**4. Каталог разделов.** Пять карточек с картинкой (кадр фрагмента), коротким описанием и числом
вопросов: все разделы, осмотр и ABCDE, СЛР и АНД, дыхательные пути и вентиляция, вызов СМП и команда.

**5. Боковая панель.** «Зачем это» и «Прошлые прохождения» живут в колонке со своей прокруткой
(`position: sticky` + `max-height`), до низа истории можно добраться, не прокручивая весь тест.

**6. Ссылка в вердикте и голос.** Слова «инструкции по ЭМП» в вердикте стали ссылкой на инструкцию.
Голос: если браузер закрыл распознавание без текста, приложение слушает ещё раз (до двух попыток) и
только потом просит повторить; во время записи кнопка работает как «Стоп»; на http-адресе честно
предупреждает, что нужен https.

`pytest` — 49 passed. Проверено в браузере: каталог, оба режима, повторное завершение (история не растёт),
ссылка на инструкцию, отдельная прокрутка панели, распознавание со второй попытки.

## Как обновлять

1. Забираете `ekstrenka_vN_YYYY-MM-DD.zip` из корня рабочей папки.
2. Распаковываете, содержимое `project/` заливаете в репозиторий (или на сервер).
3. `README_PROJECT.md` — для себя и новых участников, `README_PROGRAM.md` — для команды разработчиков,
   `DEPLOY_SHORT.md` (внутри `project/`) — пошаговая заливка на сервер.

Новая версия = новая папка `versions/v14_…`, старые не удаляю: по ним видно, что и когда менялось.
