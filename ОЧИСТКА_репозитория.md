## 5. Как удалять на GitHub (быстро)

1. Открыть https://github.com/yes0rr/ekstrenka
2. Нажать на файл или папку → значок **⋯** справа вверху → **Delete directory** → **Commit changes**.
   Для папки удаление одной кнопкой, руками ничего перебирать не нужно.
3. После очистки — залить v32 (Upload files → содержимое папки `project`).
