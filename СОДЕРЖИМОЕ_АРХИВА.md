# Что внутри архива v35 (24.11.2026)

Это архив **исходного кода** сайта «Экстренка». Распаковывать нужно так,
чтобы папки `backend` и `frontend` лежали в корне каталога сайта (`/opt/ispytaniya`).

| Папка / файл | Что это |
|---|---|
| `backend/` | сервер на Python (FastAPI): вопросы (`app/quizbank.py`), проверка ответов (`app/answermatch.py`), страницы, база |
| `frontend/` | сайт: `html/` страницы, `js/`, `css/`, `media/` видео-фрагменты |
| `tools/` | служебные скрипты: датасет, превью, скачивание моделей |
| `data/` | сюда программа сама создаст базу `app.db` (в архиве её нет — это правильно) |
| `train_data/` | шаблон журнала съёмки для датасета |
| `versions/` | история версий (`VERSIONS.md`) |
| `main.py`, `run.py`, `run_local.py` | точки входа для разных способов запуска |
| `requirements*.txt` | список библиотек для установки |
| `start.bat`, `start.sh`, `Dockerfile` | скрипты запуска |
| `*.md` в корне | инструкции и памятки (для сдачи и для команды) |

**Чего в архиве НЕТ (и не должно быть):**
- `.env` — пароли и флаги, файл свой на каждом компьютере/сервере (образец — `.env.example`);
- `data/app.db` — база пользователей и попыток, на сервере она уже есть;
- `backend/models/*.onnx` — веса моделей, качаются отдельно скриптами из `tools/`.

**Обновление на сервере:** залить файлы в `/opt/ispytaniya` (не трогая `.env` и `data/`),
затем `chown -R ispytaniya:ispytaniya /opt/ispytaniya` и `systemctl restart ispytaniya`.
